## 2. Core Philosophy & UX

The overarching design rule: **abstract the complexity. The software should "just work."**

- **Opinionated design** — optimize for a streamlined, frictionless experience over infinite layout flexibility.
- **Zero-friction onboarding** — start taking notes instantly, no mandatory upfront login, complicated setup, or paywalled basic sync.
- **Minimalist UI** — third-party icons and context menu items are strictly controlled; anything non-essential to writing gets tucked away.

## 3. Privacy, Security & Freedom

- **Open source** — free and open-source software (FOSS).
- **Data sovereignty** — full user control, with a seamless, with an easy one-step self-hosted install (Dockerized, for Desktop or VPS).
- **Top-tier security** — encrypted by default.
- **Opt-in first** — bring-your-own model option, tools for users to _re-train_ local model on their data; any telemetry or training data use is strictly anonymized and opt-in, never default.

## 4. Tech Stack

- **Framework:** React Native — cross-platform deployment.
- **Backend:** Supabase — Postgres, auth, edge functions.
- **UI Components:** Gluestack UI.
- **Data Sync:** PowerSync — to deliver that "always synced" Apple Notes feel.

## 6. Development Roadmap

**Phase 1 — MVP: The Open-Source Apple Notes Replacement** Capture the magic of Apple Notes, but cross-platform and self-hostable from day one.

- Instant-open, open-source Apple Notes replacement.
- Silent, reliable background syncing.
- Simple self-hosting documentation.

**Phase 2 — The Differentiators: Freedom & AI**

	- Public API for developers to read/write their own notes programmatically.
- Local/opt-in AI features (bring your own key).

**Phase 3 — The Ecosystem: Extensibility**

- App marketplace for community plugins, without bloating the core app.
- Easy install — one-step Dockerized self-host install (PC or VPS).
